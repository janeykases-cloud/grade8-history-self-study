# 時光關係所｜宋元到明清學生自學網站

下載或開啟 index.html，即可在瀏覽器使用；不需安裝、不需網路。

包含 8 個單元、13 個年代定位按鈕、8 組排序、16 題即時訂正與 6 題總結挑戰。

完成單元條件：該單元排序正確，且兩題練習均訂正完成。總結挑戰依每題第一次作答計分，6題同權重，百分制四捨五入；重新挑戰須確認清除本次成績。反思不自動評分。

瀏覽器可用時會保存進度；不會傳送到教師端。建議學生使用自己的瀏覽器，或在共用設備使用不同的瀏覽器設定檔。可下載文字學習紀錄。清除瀏覽器資料可能使紀錄消失。

資料依據：已提供的第三章頁100–111及第四章頁112–123；另將必要的政權並存年代用於定位。時間先後不直接表示因果。

驗證：JavaScript語法、資料答案索引、因果連線數量、8單元模擬渲染、排序與完成判定、1271與1279並存定位、總結100與83分計算通過。網站已透過 GitHub Pages 發布；瀏覽器驗證結果另見發布紀錄。
